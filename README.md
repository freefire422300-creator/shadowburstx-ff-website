## 🚀 نحوه استفاده

### آپلود به GitHub Pages

1. به ریپوزیتوری خود بروید
2. به بخش **Settings** بروید
3. در سمت چپ، **Pages** را انتخاب کنید
4. در **Source** گزینه **main** را انتخاب کنید
5. **Save** را کلیک کنید
6. سایت شما در آدرس زیر موجود خواهد بود:
   ```
   https://freefire422300-creator.github.io/shadowburstx-ff-website/
   ```

1. تمام فایل‌ها را در یک پوشه قرار دهید
2. فایل `index.html` را با مرورگر باز کنید
3. آماده است! 🎉

## 🔧 نحوه سفارشی‌سازی

### تغییر نام کانال
در فایل `index.html`، تمام نمونه‌های `ShadowBurstX` را با نام خود جایگزین کنید

### تغییر رنگ‌ها
در فایل `styles.css`، متغیرهای CSS را ویرایش کنید:
```css
:root {
    --primary-color: #1a1a2e;
    --highlight-color: #e94560;
    /* ... */
}
```

### اضافه کردن سکشن‌های جدید
1. بخش HTML جدید را در `index.html` اضافه کنید
2. لینک ناوبری را اضافه کنید
3. استایل را در `styles.css` تعریف کنید
4. اگر لازم است، JavaScript را در `script.js` اضافه کنید
